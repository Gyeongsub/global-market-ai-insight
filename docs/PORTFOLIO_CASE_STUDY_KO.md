# Global Market AI Insight — AWS 최소권한 분석 도구 포트폴리오

기준일: 2026-11-01. 공개 전 검토본이며 GitHub에는 아직 게시하지 않았습니다.
핵심 기능의 실제 검증과 최종 소스 공개를 구분합니다. 사용자 직접 실습은
프로젝트 완성·보안 검토·GitHub 공개 이후 이 문서를 읽으며 진행합니다.

## 프로젝트를 한 문장으로

시장 정보를 조사할 질문을 만드는 다국어 로컬 도구와, 합성 데이터를 실제 AWS
Bedrock에서 분석하는 본인 전용 실습을 구현하고, 최소권한·시간 제한·과금 통제·
검증 후 자원 정리까지 함께 설계한 프로젝트입니다.

## 해결하려던 문제와 범위 변경

처음에는 외부 시세 API → 이벤트 기반 AWS 처리 → AI 분석을 하나의 서비스로
연결하려 했습니다. 구현 외에도 데이터 조회·화면 표시·AI 입력·재배포의 권리,
가입 시 개인정보 제공, 호출량과 과금 조건을 각각 검토해야 했습니다.

개인 학습이라는 목적을 유지하면서 불확실한 계약과 추가 가입을 피하도록 기능을
나눴습니다. 현재 정보 조사는 기존 ChatGPT 화면에서 사용자가 직접 수행하고,
AWS 학습에는 명확히 표시한 고정 합성 QLD 데이터를 사용합니다. 실제 시세로
가장하거나 API 라이선스 문제가 해결됐다고 주장하지 않습니다.

## 현재 작동하는 두 경로

| 경로 | 사용자 경험 | AWS와 비용의 경계 |
| --- | --- | --- |
| 검색 질문 도우미 | 종목·언어·질문 종류 선택 → 직접 복사·전송 → ChatGPT에서 답변 확인 | 앱의 AWS·검색 API 호출 없음. ChatGPT 사용 조건과 한도는 별도 |
| 실제 합성 분석 실습 | 검증된 임시 중계 시작 → 브라우저에서 1회 분석 → 결과 확인 → 종료 | 모델 전용 임시 역할로 도쿄 Nova Lite 호출. 재시도 없음, 출력 512토큰, 최대 5분 인가 구간 |

기존 API Gateway/Lambda/DynamoDB/ECS/Fargate 코드는 별도 학습 구조로 보존합니다.
현재 브라우저 합성 분석이 그 전체 비동기 경로를 통과한다고 설명하지 않습니다.
기존 구조는 공급자 실행·표시를 차단하고 circuit을 OPEN으로 두는 운영
정책입니다. 실제 상태는 각 검증 기록의 시점에 해당하며 새 실행 전 재확인합니다.

## AWS가 담당하는 역할

현재 제품에서 AWS는 검색 엔진이나 웹 호스팅이 아니라 **제한된 실제 AI 분석과
최소권한 운영을 배우는 실행 환경**입니다. 검색 질문 생성은 PC 안에서 끝나고,
합성 분석을 명시적으로 시작했을 때만 Bedrock에 요청합니다.

```text
검색 질문 도우미
  로컬 웹 화면 → 질문 복사 → 사용자가 ChatGPT에 전송 → ChatGPT에서 확인

실제 AWS 합성 분석
  소유자 인증 → 임시 모델 전용 역할 → 단기 STS 자격증명
                                      ↓ 브라우저에는 전달하지 않음
  로컬 웹 화면 → 제한된 중계 → Bedrock Nova Lite → 결과 검증 → 화면 표시
                                      ↓
                      세션 종료 → 자격정보 정리 → 역할·스택 삭제 확인
```

| 구성 요소 | 이 프로젝트에서 맡는 일 | 선택하지 않은 대안과 이유 |
| --- | --- | --- |
| 로컬 웹 화면·중계 | 본인 PC에서 요청·결과 표시, AWS 인증은 서버 쪽에만 보관 | 공개 웹 호스팅은 도메인·인증·운영 범위를 추가하므로 현재 목적에서 제외 |
| IAM 역할·STS | 분석에 필요한 제한된 권한을 단기간 부여 | 관리자 자격증명을 브라우저나 분석 SDK에 전달하지 않음 |
| Amazon Bedrock | 고정된 합성 자료에서 제한된 분석 항목을 선택 | 외부 주가 API 추가 가입이나 실제 금융 데이터 이용권이 필요 없는 실습 |
| AWS CDK·CloudFormation | 임시 역할과 보존된 AWS 학습 구조를 코드로 설명·관리 | 콘솔에서 수동 변경만 누적하는 방식보다 변경과 정리 절차를 추적하기 쉬움 |
| API Gateway·Lambda·DynamoDB·Fargate | 과거 비동기 작업·중복 방지·상태 전이 학습 코드 보존 | 현재 직접 Bedrock 경로의 필수 실행 요소라고 과장하지 않음 |

보존된 구조의 DynamoDB는 작업 상태와 조건부 전이를, Fargate는 작업별 컨테이너
실행을 다룹니다. 이 선택은 장시간 상주 서비스를 유지하는 것과 다릅니다.
단, 현재 제품의 분석 버튼이 이 구조를 실행하지는 않습니다.

## 설계에서 배운 핵심

1. **인증과 인가 분리:** 소유자의 CLI 로그인은 인프라 관리에만 쓰고, 분석 SDK는
   별도의 모델 전용 STS 자격증명을 받습니다. 브라우저에는 AWS 키가 없습니다.
2. **통제의 적용 범위 명시:** STS 수명 15분, 세션 정책의 절대 허용 구간 5분,
   애플리케이션의 모델 시도 1회는 서로 다른 통제입니다. 재시작은 새 허용량입니다.
3. **성공뿐 아니라 거부도 검증:** 허용 모델 호출, 만료 후 명시적 거부, 다른 역할의
   접근 거부와 ECS 실행 거부를 각각 제한된 시험으로 확인했습니다. 모든 권한을
   포괄적으로 검증했다는 의미는 아닙니다.
4. **모델 응답도 신뢰하지 않기:** 고정 근거에서 허용된 인사이트 ID만 선택하게 하고,
   스키마·사용 토큰·필수 위험 문구를 검증한 뒤 앱이 지역화된 문장을 표시합니다.
5. **종료를 기능의 일부로 설계:** 화면 CLOSED, 로컬 리스너 종료, 자격정보 해제,
   임시 역할·스택 삭제, 별도 조회를 통한 잔존 확인을 구분했습니다.

## 실제로 확인한 결과

- 10월 31일 최소권한 브라우저 검증 리비전은 동일 소스의 현재 설치와 격리된
  새 설치에서 90단계, 1,874개 테스트 통과 및 기존 skip 1건을 확인했습니다.
- 11월 1일 후속 검증은 90단계, 1,897개 통과 및 기존 skip 1건입니다.
  현재 설치와 새 설치 사이에 계획 문서가 변경되어 소스 해시는 다릅니다.
  이 숫자를 현재 최종 공개 후보의 동일 해시 검증으로 사용하지 않습니다.
- 10월 31일 최소권한 브라우저 경로로 영어 합성 QLD 분석을 1회 수행했습니다. 입력 895,
  출력 93토큰이었으며 결과 새로고침과 페이지 재로딩은 추가 모델 요청을 만들지
  않았습니다. 해당 요청의 당시 요율 계산은 USD 0.000091224이고 확정 청구액은 아닙니다.
- 종료 후 임시 역할·스택 삭제를 독립 조회했고, 프로젝트의 실행/대기 작업·서비스·
  점유 슬롯이 0인 상태를 확인했습니다. 보관 중인 저장소의 비용까지 0이라는 뜻은 아닙니다.
- 한 차례 로컬 서비스 테스트 실패는 정확한 원인을 확인하지 못했습니다. 이후
  독립 실행들은 통과했지만 실패를 삭제하거나 원인을 추정해 확정하지 않았습니다.

자세한 범위는 [실제 브라우저 검증 증거](evidence/SYNTHETIC_RESTRICTED_BROWSER_2026-10-31.md)에 있습니다.

## 보안과 비용을 통제한 방법

분석 요청을 1회로 제한한 이유는 AI 출력의 품질뿐 아니라 예상치 못한 반복
호출을 막기 위해서입니다. 실패도 횟수에 포함하고 SDK 재시도를 끕니다.
출력 토큰 제한은 응답 크기를 제한하지만 입력·다른 서비스·새 세션의 비용까지
막는 계정 전체 한도는 아닙니다.

| 통제 | 막으려는 문제 | 남는 한계 |
| --- | --- | --- |
| 127.0.0.1 전용 접근·요청 검증 | LAN 노출과 의도하지 않은 브라우저 요청 | 악성 코드가 실행 중인 PC까지 신뢰할 수 있게 만들지는 않음 |
| 고정 모델·리전·합성 입력 | 다른 모델 사용, 민감한 자유 입력 전송 | 기능 범위가 좁으며 일반적인 투자 분석 서비스가 아님 |
| 모델 전용 역할 | 분석 프로세스의 비밀 조회·컴퓨팅 실행 권한 제한 | 소유자의 별도 관리 인증에는 다른 권한이 존재할 수 있음 |
| 5분 인가·15분 STS·1회 앱 시도 | 장시간 사용과 반복 호출 제한 | 역할 삭제만으로 발급된 모든 세션이 즉시 취소된다고 볼 수 없음 |
| 검증된 항목 ID·지역화 문장 | 임의 모델 문장이나 HTML을 그대로 표시하는 위험 | 제한된 합성 사례의 결과이며 사실성 전반을 보증하지 않음 |
| 종료 후 독립 조회 | 정리 명령의 성공 메시지만 믿는 문제 | 검사 범위 밖 리소스와 지연 청구까지 제거됐다는 보증은 아님 |

월 USD 5 예산 알림은 초과를 알려주는 장치이지 강제 차단기가 아닙니다.
실습을 실행하지 않아도 보관된 S3·ECR·DynamoDB·로그 등에는 비용이 남을 수
있습니다. 이 프로젝트는 ‘항상 무료’가 아니라 **실행 범위와 잔존 비용을
설명하고 종료를 검증하는 운영**을 목표로 합니다.

## 문제 해결 사례

**시장 데이터의 이용 조건:** API 연결 성공과 데이터를 표시·AI 입력으로
사용할 권리는 별개였습니다. 무료 대체 공급자 가입을 늘리는 대신 실제 정보는
사용자 ChatGPT 화면에서 확인하고 AWS에는 합성 입력을 보내도록 분리했습니다.
기술적 연결보다 요구사항과 운영 제약을 먼저 정리한 결정입니다.

**모델 호출과 응답 처리:** 실제 요청 실패는 로컬 호환성 검토와 제한된
재검증으로 다뤘습니다. 성공한 응답의 사용량, 새로고침 후 호출 수, 허용 시간
이후 거부를 각각 확인했습니다. 정상 요청 1회가 전체 IAM 정책의 완전한
안전성을 증명하지는 않습니다.
[호환성 수정 및 만료 검증](evidence/SYNTHETIC_USAGE_COMPATIBILITY_2026-10-31.md).

**개발 의존성의 보안 공지:** 10월 31일 조회에서 개발용 minimatch 두 버전에
중간 등급 공지 1건이 매칭됐습니다. 선언된 실행 의존성 매칭은 0건이지만
‘취약점 없음’으로 바꾸지 않았습니다. 고정된 lint 입력, 제한 시간과 메모리
설정은 위험 완화이며 패치가 아닙니다. 이후 11월 1일에는 10.2.6의 두 모듈
형식에 공식 수정 기반의 호환 패치를 적용했고, 전체 로컬 검증은 90단계,
1,905개 통과·기존 skip 1건으로 끝났습니다. 원래 버전 범위 공지와 다른 구현인
3.1.5의 검토는 보존합니다. 공개 사본의 독립 재현과 최종 위험 결정은 별도입니다.
[패치와 검증 기록](evidence/MINIMATCH_BACKPORT_2026-11-01.md).
[보안 공지 검토](evidence/LINT_ADVISORY_REVIEW_2026-10-31.md).

## 과장하지 않아야 할 부분

실시간 주가 서비스, 투자 권고 서비스, 공개 사용자용 인증 시스템, 무조건적인
비용 상한, 모든 장애에서의 즉시 과금 중단을 구현했다고 주장하지 않습니다.
새 최소권한 경로의 실제 검증은 영어 1회이며, 이전 다른 언어 시험과 구분합니다.
원격 CI·공개 저장소 재현·이미지/라이선스/전체 Git 이력 검토와 GitHub 업로드는
최종 공개 단계의 별도 작업입니다.

AI의 도움으로 구현·검증한 프로젝트입니다. 본인이 직접 수행한 조작과 AI가
수행한 구현을 구분하고, 아직 직접 수행하지 않은 실습을 경력으로 적지 않습니다.
[학습 안내서](API_INTEGRATION_LEARNING_GUIDE_KO.md)의 코드 추적·설명 질문을 통해
본인이 구조와 운영 판단을 이해했는지 점검할 수 있습니다.

## 완성 후 읽는 순서

실습은 공개 완료 후에 진행합니다. 읽는 것만으로 운영 숙련도가 입증되지는
않지만, 아래 순서로 설계 이유와 코드를 연결하면 실제 조작의 목적을 이해할 수
있습니다. 첫 독해에는 AWS 로그인이나 유료 모델 호출이 필요하지 않습니다.

1. [현재 계획](../plan.md)에서 두 활성 경로와 보존된 학습 경로를 구분합니다.
2. [아키텍처](architecture.md)에서 요청·데이터·인증이 각각 어디로 이동하는지
   설명합니다. 브라우저에 AWS 키가 없는 이유를 확인합니다.
3. [한국어 API/AWS 안내서](API_INTEGRATION_LEARNING_GUIDE_KO.md)로 과거 API
   연동과 현재 합성 실습의 차이, IAM·STS·비용 통제를 연결합니다.
4. [합성 실습 운영 절차](runbooks/synthetic-bedrock-lab.md)에서 시작 조건과
   종료 조건을 먼저 읽습니다. 실제 실행은 최신 인증·비용·안전 조건 확인 후 합니다.
5. [검증 결과 목록](PRIVATE_PORTFOLIO_STATUS.md)에서 성공·거부·실패·미검증을
   구분하고, 결과를 직접 재현한 뒤에만 본인의 실습 경험으로 기록합니다.

### 설명할 수 있어야 할 질문

- 왜 공개 서버 대신 로컬 중계를 선택했고, 무엇을 포기했는가?
- 임시 자격증명 수명, 권한 허용 시간, 앱 호출 횟수는 어떻게 다른가?
- Fargate가 현재 분석 버튼의 실행 경로에 포함되지 않는 이유는 무엇인가?
- 알림이 울리기 전에도 비용을 제한하려면 어느 지점에서 무엇을 막아야 하는가?
- 성공 응답 외에 어떤 거부·종료 증거가 있어야 안전한 실습이라고 설명할 수 있는가?

이 질문들은 공개 전 사용자에게 요구하는 과제가 아니라, 공개 후 자기 주도
학습과 면접 설명을 위한 점검표입니다.

## 5분 설명 순서

1. 추가 가입·시세 이용 권리·비용 때문에 기능을 분리한 이유를 설명합니다.
2. 검색 화면에서 질문과 출처 요구사항을 보여주되 자동 전송하지 않습니다.
3. 과금 없는 기록/스크린샷으로 실제 AWS 분석과 최소권한 경로를 설명합니다.
   시연을 위해 무조건 새 유료 호출을 반복할 필요는 없습니다.
4. 거부 시험과 종료 증거를 보여주고, 알림·권한·횟수·수명 제한의 차이를 설명합니다.
5. 현재 완성 범위와 [남은 공개 검토](PRIVATE_PORTFOLIO_STATUS.md)를 명확히 구분합니다.
