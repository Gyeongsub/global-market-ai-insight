## 판단의 한계와 저장 조건

- Alpha Vantage의 약관은 개인적 분석·연구·테스트를 허용 범위로 설명하고,
  공식 지원 페이지는 LLM용 MCP를 직접 연결한다. 이를 개인용 AI 추론의 긍정적
  근거로 해석했으며 모든 AI 용도나 공개 재배포를 허용한다고 확대하지 않았다.
  MCP 사이트 본문은 도구에서 거의 추출되지 않아 지원 페이지의 명시적 안내에
  근거했다. 교육용 무제한 호출은 별도 검증 대상이며 이 계정에 적용하지 않는다.
- Massive의 AI 안내는 보유 entitlement를 그대로 따른다. 일반 마케팅보다
  시장데이터 약관의 제한을 우선 보수적으로 적용한다. 개인/비전문가 분류 및
  유료 add-on 조건도 남으므로 자동 가입하지 않는다.
- FMP 약관이 참조한 추가 데이터 이용 정책은 이번 도구에서 열리지 않았다.
  읽지 못한 정책을 통과로 취급하지 않는다. 무료 한도 초과 시 차단 설명은
  [공식 FAQ](https://site.financialmodelingprep.com/faqs?code=analyst)에 있지만,
  가입하지 않았으므로 계정별 과금 설정은 검증하지 않았다.
- Finnhub는 구독 종료 시 해당 데이터 삭제를 요구한다. 다른 후보의 명시적인
  캐시 최대 기간·장기 보관 권리를 이번 근거만으로 확정하지 않았다.
  캐시를 사용하지 않는다고 모든 보관·제3자 처리 조건이 해결되는 것은 아니다.

## 채택을 승인받은 경우에만 검토할 구현 범위

1. 개인 무료 가입 조건을 사용자가 확인한다. 카드·유료 체험·자동 업그레이드·
   사용량 기반 결제는 추가하지 않는다. 키는 채팅/브라우저 코드/로그가 아닌
   기존 서버 측 비밀 관리 경로로 설정한다. 지금은 수행하지 않았다.
2. 우선 계정 전체 25회/일보다 낮은 로컬 정책(예: 20회/일, 나머지 확인 여유)을
   검토한다. 이것은 제안일 뿐 구현·실제 공급자 계량 증거가 아니다. 실패·조회·
   종목 검색도 예산에 포함하고 백그라운드 갱신·무제한 재시도는 금지한다.
3. VOO/QLD/TSLA/SPCX/GOOG의 정확한 종목·통화·거래일을 검증한다. 지원 범위
   광고를 다섯 종목의 실제 응답 증거로 쓰지 않는다. 특히 SPCX는 대체하지 않는다.
4. 일말 데이터의 날짜를 실제 거래소 시각으로 꾸며 넣지 않는다. 기존 최신성
   검사·주말 처리·표시 라벨과 데이터 계약을 검토한 뒤에만 어댑터를 채택한다.
5. Bedrock에는 필요한 검증 필드만 전달하고 키·계정정보·원문 응답을 넣지 않는다.
   모델 학습, 공개 결과 공유, 장기 캐시는 별도 범위다. AWS 추론·Fargate 비용은
   공급자 무료 요금과 별개이며 기존 한 건 제한·종료 검증을 계속 적용한다.

이번 조사는 공급자 선택/전환 또는 실제 호출의 승인이 아니다. 연구 결과를
검토한 뒤 공급자 채택과 가입 여부를 별도로 정한다. GitHub 공개는 계속 보류한다.
