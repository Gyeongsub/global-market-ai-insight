# Current source versus retained bundles — 2026-10-16 resume

Local protection only; no live proof, cloud mutation, app job, image rebuild,
deployment, IAM change, registry credential or publication was performed here.

The standalone controller/worker read-only release tools previously compared a
live archive with generated local bundle files. That comparison alone could
accept old generated files after source edits. A successful historical image
comparison must not be treated as current-source provenance.

Both tools now run the existing backend module verifier before any AWS read
and again before success. That fixed local verifier rebuilds all four backend
targets twice in memory, compares generated bytes, brackets the actual input
set, and rechecks the lock and written artifacts. All four generated backend
bundles must be current first; a stale or missing unrelated target also blocks
the operation. This conservative local prerequisite does not add AWS scope.

The subprocess uses the current Node executable, one fixed script, a 30-second
limit and a 100,000-byte output bound. Its environment contains only OS/temp
settings and a disabled compile cache, not cloud/provider keys, proxies, Node
hooks or caller-selected commands. It does not write build output or execute
the application. Fixed failure messages suppress child logs and private paths.
The selected artifact hash and lock must agree at both ends of the live proof.
Default plans and imports remain inert; no new cloud permissions are needed.

An actual local run against the retained root bundles rejected them. A separate
diagnostic confirmed the exact fixed failure stage
`BACKEND_MODULE_PROOF_CONTROLLER_ARTIFACT_MATCH_INCOMPLETE`, rather than an
unrelated executable/environment failure. No AWS or network request occurred.
Synthetic tests cover stale bytes, duplicate/missing targets, incomplete input
bracketing, side-effect claims, invalid selectors and both operator orderings.
Strict operator type checking and the final whole-scope result are recorded
separately; this note is not a successful live source/image verification.

The whole-check JavaScript helper and frontend artifact test lists now use
bounded physical-directory discovery instead of static file lists. New nested
`.test.mjs` files are included automatically, once, at concurrency two; empty,
redirected, special-file or excessive scopes fail closed. The retired-key
observation tests had been omitted from the earlier 1,111-test aggregate and
are explicitly asserted present. That earlier pass remains historical, not
the final verification of this later scope. No tests, deadlines, release
blocks or credential/privacy detectors were relaxed.
