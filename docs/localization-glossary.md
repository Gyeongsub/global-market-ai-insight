# Localization Glossary

Use these terms consistently in primary UI, fixtures and model-output evaluation.

| Concept | English | Japanese | Korean |
|---|---|---|---|
| latest available | Latest available | 最新利用可能 | 최신 가용 |
| previous close | Previous close | 前日終値 | 이전 종가 |
| delayed | Delayed | 遅延 | 지연 |
| market closed | Market closed | 市場終了 | 시장 마감 |
| market timestamp | Market timestamp | 市場時刻 | 시장 시각 |
| retrieval timestamp | Retrieved at | 取得時刻 | 조회 시각 |
| data source | Source | データソース | 데이터 출처 |
| uncertainty | Uncertainty | 不確実性 | 불확실성 |
| daily leverage | Daily leverage | 日次レバレッジ | 일일 레버리지 |
| path dependency | Path dependency | 経路依存性 | 경로 의존성 |
| financial advice | Financial advice | 金融アドバイス | 금융 자문 |
| data unavailable | Data unavailable | データ利用不可 | 데이터 이용 불가 |
| queued | Queued | 待機中 | 대기 중 |
| running | Running | 実行中 | 실행 중 |
| timed out | Timed out | タイムアウト | 시간 초과 |

Ticker symbols, ISO timestamps, currency codes and API error codes are not translated. `Real-time` is localized only when provider entitlement and metadata prove that label is accurate.
